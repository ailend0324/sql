# 售后数据

存放所有售后相关的 SQL 查询脚本，是日常使用频率最高的目录之一。

## 核心脚本

| 文件 | 说明 |
|------|------|
| **多平台售后明细数据.sql** | 当前生产版本，覆盖竞拍+鱼市+多平台的售后明细汇总 |
| **多平台售后明细_优化版.sql** | 性能优化版，建议逐步替换上面的版本 |

## 子目录

| 目录 | 说明 |
|------|------|
| **竞拍售后/** | 竞拍售后明细、成本、重检归类 |
| **鱼市售后/** | 鱼市 B 端/C 端售后明细 |
| **检测选项/** | 售后检测选项明细、QC 明细注释版 |
| **参考文档/** | 字段命名规范、对照表、鱼市映射表等 |
| **截图资料/** | 售后检测模块归属、血缘关系等截图 |
