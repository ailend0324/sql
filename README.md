# SQL 数据查询脚本库

> 这是一个**生产环境在用**的 SQL 脚本仓库，覆盖回收宝核心业务的数据查询、报表生成、实时监控等场景。
> 靠这套脚本体系，省掉了一个数据运营岗位的人力成本。

---

## 目录说明

| 目录 | 说明 | 使用频率 |
|------|------|----------|
| **售后数据/** | 竞拍售后、鱼市售后、多平台售后明细等核心售后查询 | 每天用 |
| **回收业务/** | 回收订单、销售、日清、闲鱼/天猫、黄金业务 | 每天用 |
| **检测管理/** | 检测绩效、QC质检、分模块检测、预警播报 | 每天用 |
| **供应链/** | 收货管理、物流管理、仓储与退货 | 每天用 |
| **验货宝/** | 验货宝履约、检测差异、到货预测 | 经常用 |
| **实时监控/** | 实时估价、下单、压价、议价等看板数据 | 每天用 |
| **财务数据/** | 财务毛利、营收报表 | 定期用 |
| **数据维度表/** | 渠道维度表、统一数据指标字典 | 参考用 |
| **工具与自动化/** | Hue 自动化执行工具 | 工具类 |
| **AI协作指南/** | AI 辅助写 SQL 的最佳实践和配置 | 参考用 |
| **学习资料/** | SQL 学习路径、练习题、模板库 | 学习用 |
| **版本归档/** | 历史版本存档（全平台售后、多平台售后演进、供应链效能演进） | 备查用 |
| **待整理/** | 暂时无法确定归属的文件，后续再处理 | 待定 |

## 注意事项

1. **这是生产环境脚本**，修改前请先备份或创建新分支
2. 优化版脚本已替代原版放在正式目录，原版保存在 `版本归档/` 中
3. `待整理/` 目录中的文件暂未确定用途，请勿随意删除
4. 如需查看某个脚本的历史版本，可通过 `git log` 查看提交记录
