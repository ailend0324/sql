# 检测管理

存放检测绩效、QC 质检、分模块检测、预警播报相关脚本。

## 子目录

| 目录 | 说明 |
|------|------|
| **绩效与产出/** | 检测绩效数据指标、检测作业数据、检测豹操作记录等 |
| **QC质检/** | QC 抽检明细、QC 数据、重检差异明细 |
| **分模块检测/** | 分模块实时产出、未出报告、各模块作业量、自动化检测记录 |
| **预警与播报/** | 退货预警机器人、机器人播报、问密退货未入库播报 |

## 常用脚本速查

| 场景 | 文件 |
|------|------|
| 查检测绩效 | `绩效与产出/检测绩效数据指标.sql` |
| 查 QC 抽检 | `QC质检/QC抽检明细数据.sql` |
| 查分模块产出 | `分模块检测/分模块实时产出.sql` |
| 退货预警 | `预警与播报/退货预警机器人.sql` |
