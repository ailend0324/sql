# 供应链

存放收货、物流、仓储退货相关的 SQL 脚本。

## 子目录

| 目录 | 说明 |
|------|------|
| **收货管理/** | 收货组人员效能、各环节效能、收货日清、回收验机收货数、到货同期对比等 |
| **物流管理/** | 物流订单明细、物流节点、顺丰正向时效等 |
| **仓储与退货/** | 供应链作业明细、仓储移库、退货出库、销售出库等 |

## 说明

### 到货同期对比（2024 vs 2025）

| 文件 | 说明 |
|------|------|
| `收货管理/收货到货同期对比_2024vs2025.sql` | 按天统计回收（闲鱼 / 天猫）与验货宝的仓库实收量，覆盖 2024、2025 两年 09-15 ~ 11-30 同期 |
| `收货管理/收货到货同期对比看板.html` | 配套看板：把上面查询的 CSV 导出拖进去，自动出日/周对比曲线、同比与明细表（浏览器直接打开，无需部署） |

收货管理目录中保留了多个版本的效能脚本（原版、重构版、近30天版、优化版），可根据实际需要选用。推荐优先使用带"优化版"后缀的文件。
