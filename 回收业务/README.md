# 回收业务

存放回收宝核心回收业务的 SQL 脚本。

## 子目录

| 目录 | 说明 |
|------|------|
| **订单与销售/** | 回收全量订单、订单明细、静态报表、议价成交、客服工单等 |
| **检测日清/** | 回收检测日清、收货日清、问密日清等每日清算数据 |
| **闲鱼与天猫/** | 闲鱼上门/佣金/NPS、天猫考核、天润接听 |
| **黄金业务/** | 黄金回收数据、黄金履约、黄金综合数据 |

## 常用脚本速查

| 场景 | 文件 |
|------|------|
| 查回收全量订单 | `订单与销售/回收全量订单.sql` |
| 查回收静态报表 | `订单与销售/回收静态.sql` |
| 查每日检测日清 | `检测日清/回收检测日清.sql` |
| 查闲鱼佣金 | `闲鱼与天猫/闲鱼佣金.sql` |
